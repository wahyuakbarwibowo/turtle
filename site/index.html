Video meetings you host yourself.

A self-hosted Jitsi alternative: share a link, join from the browser, no downloads. Built on a Rust API and the LiveKit SFU, with an embed SDK so your own platform can run calls inside its UI.

Get started Documentation

What works today

Meetings

Invite links, sign-in or guest join, meetings without an account, history.

Media

Audio, video, screen share, active speaker, simulcast with adaptive stream and dynacast.

Host controls

Lobby with admit/deny, meeting password, mute one or everyone, remove, end for all.

Chat & reactions

Persisted chat with live delivery, raise hand, emoji reactions, people panel.

Integrations

API keys for other platforms, short-lived embed links, iframe SDK, HMAC-signed webhooks.

Security

Argon2id, HTTP-only sessions, room-scoped tokens, rate limits, audit log, reviewed defaults.

Embed it in your platform

Your backend creates a meeting and mints a link per user with an API key:

POST /api/integrations/meetings
{ "title": "Consultation", "external_ref": "ticket-7" }

POST /api/integrations/meetings/{code}/tokens
{ "external_id": "42", "display_name": "Budi",
  "role": "participant" }
→ { "embed_url": "https://meet.example.com/embed/…#t=…" }

Your frontend shows the call, with Jitsi-like commands and events:

<script src="https://meet.example.com/sdk/turtlemeet-embed.js"></script>

const meet = new TurtleMeetEmbed(el, { url: embedUrl });
meet.on("joined", (e) => console.log(e.role));
meet.on("readyToClose", () => meet.dispose());
meet.execute("toggleAudio");

Webhooks tell you when people join or leave and when the meeting ends. Migrating from Jitsi's External API →

Get started

Run it with Docker

git clone https://github.com/wahyuakbarwibowo/turtle
cd turtle
make deploy-env   # random secrets
make deploy-up    # http://localhost

On a VPS with HTTPS: make deploy-up TLS=1. Deployment guide →
